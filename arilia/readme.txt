A bright, fruit-forward block theme for Arilia, the 250 ml pure fruit wellness collection.

== Description ==

* Home, Products, Our Story, Contact & Distribution and seven flavour pages built from core blocks.
* Flavour cards and heroes with individual bottle artwork and colour tints.
* Plugin-free enquiry form (emails you, stores nothing).
* Guided setup screen: contact details, starter pages, layout upgrades.
* Open Graph and structured data, bundled web fonts, no third-party requests.

== Installation ==

1. Back up your site (files + database).
2. Appearance > Themes > Add New > Upload Theme. Choose Arilia-WordPress-Theme.zip and click Install Now. When updating, choose "Replace current with uploaded".
3. Activate the theme.
4. Appearance > Arilia Setup:
   * Save your enquiry email, phone, WhatsApp number and social links.
   * First install: click "Create missing starter pages". Leave the checkboxes unchecked to create drafts for review, or tick them to publish and set the homepage.
   * Updating from 1.x: click "Upgrade page layouts". WordPress keeps the old content as a revision on each page.
5. Appearance > Editor > Header: add your logo to the Site Logo block (optional; the wordmark is used otherwise).
6. Settings > General: upload a Site Icon.
7. Open the Contact page and send a test enquiry. If it does not arrive, check spam, then install an SMTP plugin.

== Editing ==

* Pages > All Pages: edit copy, images, links and buttons with the block editor.
* Appearance > Editor: header, footer, styles, colours and typography.
* Pages > Add New > Patterns > "Arilia pages": insert another copy of a starter page or section (flavour cards, Stock Arilia band).
* To add a flavour: duplicate a flavour page, change the text and image, then add a card on Products.
* Product labels remain the source of truth for ingredients, nutrition, allergens and storage; the theme makes no such claims.

== Rollback ==

Activate the previous theme from Appearance > Themes, or restore the backup. Page content changed by "Upgrade page layouts" can be restored from each page's Revisions.
