ARILIA WORDPRESS THEME — VERSION 1.0.0

INSTALL THIS ZIP THROUGH WORDPRESS THEMES, NOT THE GODADDY WEBSITE BUILDER.

WHAT IS INCLUDED
- Home, Products, Our Story, Contact & Distribution.
- Seven separate flavour pages: Pomegranate, Mango, Strawberry, Cranberry,
  Dragon Fruit, Pomegranate + Apple, Beet + Lime + Ginger.
- POM-inspired product-category layout with original Arilia bottle artwork,
  individual colour treatments, and Mango in the middle of the group image.
- Native WordPress blocks for editable text, images, links, page sections,
  header, footer, navigation, colours and typography.
- Phone, WhatsApp and email links. No contact-form database is created.
- No paid page builder, plugin, store, checkout or payment account required.

REQUIREMENTS
WordPress 6.6 or newer, PHP 8.0 or newer. Use a currently supported PHP version
offered by your host. This is a WordPress block theme. It is not a static
website ZIP, a WordPress database backup, or a GoDaddy Website Builder theme.

INSTALL ON GODADDY MANAGED WORDPRESS
1. Set up your WordPress hosting account. Use the temporary address while
   reviewing the website. Do not change the domain's DNS during this review.
2. Open WordPress Admin (the dashboard with Pages, Appearance and Plugins).
3. Choose Appearance > Themes > Add New Theme > Upload Theme.
4. Select Arilia-WordPress-Theme.zip. Upload the ZIP without extracting it.
5. Click Install Now, then Activate.
6. Open Appearance > Arilia Setup (or the Open Arilia Setup notice).
7. Click Create Arilia Starter Pages. With all checkboxes left unchecked,
   this creates 11 draft pages and preserves the current homepage and title.
8. Open Pages > All Pages. Edit Home or Products and click Preview. Draft
   preview links require you to be signed into WordPress.

STARTER IMPORT OPTIONS
- Publish new starter pages now: only select after reviewing the starter
  design and if you want newly created pages to be public immediately.
- Make Home the homepage: applies only if Home is published. Otherwise,
  publish Home later and use Settings > Reading > A static page > Home.
- Set site title: changes Settings > General to Arilia and the brand tagline.

The importer refuses unrelated pages with conflicting slugs. It does not
overwrite previously imported content. Repeating the import does not publish
existing draft pages. To publish reviewed drafts, select them in Pages > All
Pages and use Bulk Actions > Edit > Status: Published. To keep an existing
website live, use a staging or temporary WordPress installation for this work.

EDIT CONTENT
- Pages > All Pages: edit the text and artwork using the block editor.
- Products: the two category sections contain ordinary Group blocks. Use
  List View to find a product card, then change its heading, description,
  image or button link. Each button opens its individual flavour page.
- New flavour: duplicate or copy an existing flavour page's blocks, then
  add a matching card to Products. No special product plugin is used.
- Image block Styles: the named Arilia bottle styles crop one bottle from
  the supplied seven-flavour group artwork. When replacing that image with
  a new standalone bottle photo, choose the Default image style first.
  That prevents the new photo being cropped as if it were the group image.
- Appearance > Editor: edit Header/Footer template parts and Styles.
  The menu is a native Navigation block; update it in the shared Header.
- Email/phone/WhatsApp appear in page content and the Footer. Update each
  relevant page/pattern copy and the shared Footer when details change.
- A theme update does not automatically update imported page content.
  WordPress stores your edits in its database. Keep database backups.

BEFORE PUBLIC LAUNCH
1. Review all 11 pages on desktop and mobile. Verify the navigation, every
   flavour link, email client, phone dialler and WhatsApp handoff.
2. Confirm final artwork, product labels, ingredient wording, availability
   and the business's final public copy. Images are concept/mockup artwork.
   The theme does not assert juice percentage, nutrition, shelf life,
   certifications or medical benefits. No prices or stock were invented.
3. Publish the reviewed pages and assign Home as the static homepage.
4. Connect drinkarilia.com through the GoDaddy WordPress hosting dashboard.
   Configure HTTPS for the root and www names and choose the preferred
   address https://www.drinkarilia.com. Preserve unrelated email DNS records.
5. Set the preferred WordPress/Site address through the supported GoDaddy
   domain connection process. Do not hardcode a temporary URL in templates.
6. If you built on a temporary domain, use the hosting platform's supported
   URL migration/search-and-replace for stored page and navigation links.
   Relative artwork paths are not assumed: image URLs are generated from
   the active theme path at import time. Check images after domain migration.
7. Settings > Reading: discourage search engines during review, then turn
   this off at launch. The theme leaves the existing choice unchanged.
8. Settings > Permalinks: choose your desired structure. Both plain and
   pretty permalinks are supported. Recheck navigation after changing it.
9. WordPress supplies canonical links and its /wp-sitemap.xml sitemap.
   The theme adds page descriptions from excerpts; it skips these when
   Yoast, Rank Math or All in One SEO is detected.
10. Review privacy information for any analytics, forms, cookies or other
    plugins you subsequently enable. No analytics or form tracking is bundled.

BACKUP AND ROLLBACK
Before activation on an existing site, take a full files + database backup.
To revert the appearance, activate the previous theme. Imported pages remain
in Pages and can be moved to Trash individually. Restore the previous homepage
in Settings > Reading if you selected the homepage option. A full host backup
is the route to restoring previous template/editor and database state.
