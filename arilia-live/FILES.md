# Theme file map

The existing static website was preserved. This is a separate WordPress theme.

| File | Purpose |
|---|---|
| style.css | Theme identity, requirements and licence |
| theme.json | Editor palette, typography, layout and template declarations |
| functions.php | Theme support, stylesheet loading, patterns and page descriptions |
| inc/content.php | Starter core-block content, product catalogue and contact links |
| inc/setup.php | Admin setup screen and safe, explicit starter-page import |
| assets/site.css | Responsive frontend and editor styling |
| assets/collection.webp | Supplied seven-flavour lineup, Mango centred |
| assets/pomegranate.webp | Supplied hero bottle artwork |
| assets/pomegranate-apple.webp | Supplied combination bottle artwork |
| templates/index.html | Blog/archive fallback |
| templates/front-page.html | Editable homepage shell |
| templates/brand-page.html | Full-width brand/product page shell |
| templates/page.html | Generic pages with an automatic title |
| templates/single.html | Standard blog article template |
| templates/404.html | Accessible missing-page template with search |
| parts/header.html | Shared header pattern insertion |
| parts/footer.html | Shared footer pattern insertion |
| README.txt | Installation, content editing, launch and rollback instructions |
| VALIDATION.md | Requirements and verification limits |
| FILES.md | This file map |
| LICENSE | GPL v2 text for theme code |

The installable ZIP excludes the local test WordPress environment, npm
dependencies, fixture pages, generated test output and transfer helpers.
