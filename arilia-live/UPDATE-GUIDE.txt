ARILIA 1.2 DESIGN UPDATE

1. Create a GoDaddy backup of the current WordPress site.
2. WordPress > Appearance > Themes > Add New > Upload Theme.
3. Upload Arilia-WordPress-Theme.zip.
4. Review the installed/new theme comparison, then choose Replace current with uploaded.
5. Clear the GoDaddy site cache and reload the website in a private window.

Do NOT recreate starter pages. This update styles your existing Arilia pages.
Page text, images, page IDs, links and publishing status remain in WordPress.
If you edited theme files separately, back them up before replacing the theme.

Check Home, Products, each flavour, Our Story and Contact on desktop and phone.
Verify full bottles, aligned cards/buttons, no sideways scrolling, mobile menu,
keyboard focus and contact destinations. No messages were sent during testing.

Rollback: restore the previous theme ZIP or GoDaddy backup.

Changed files versus 1.0:
style.css: version 1.1.0.
functions.php: loads refinement CSS on the site and in the editor.
assets/refinement.css: typography, spacing, image proportions, grid, footer,
contact button hierarchy and responsive styles.
assets/bottle-mask.svg: presentation mask for the original group artwork.
UPDATE-GUIDE.txt and VALIDATION.md: update instructions and review status.

Artwork is the existing approved set. Product cards still reference the group
image using a display mask; separate approved product photography would be the
best next asset upgrade. No bottle labels have been repainted.

1.2 restores ruby and gold backgrounds, curved bottle displays, pastel flavour
backgrounds, decorative curves and bold headings. Alignment fixes remain.

1.3 HEADER UPDATE
Navigation: Flavours, Our Story, Contact, Stock Arilia. Logo links home.
Stock Arilia links to Contact / Distribution enquiries.
If a header was customized and saved in the Site Editor, WordPress may retain
that saved header instead of the theme default. Review it in the Site Editor;
reset only the Header customization if you want this new theme header.
Do not recreate starter pages.

paragraphs using the arilia-brand-line class. Text baked into bottle artwork
remains unchanged. Theme update does not rewrite saved page content.
